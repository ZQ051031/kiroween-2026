# Structure

- `index.html` and `styles.css`: layout, controls, responsive presentation, ambience.
- `game.js`: room content, scoring, persistence, and story generation.
- `app.js`: browser interactions, rendering, dialogs, and audio.
- `assets/`: original scene art and icons.
- `tests/`: headless Chrome smoke test; runtime app has no test dependencies.
- `.kiro/specs/haunted-hollow/`: requirements, design, and build sequence; `.kiro/steering/`: product, technology, and repository conventions.
